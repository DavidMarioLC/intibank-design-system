**Intibank Design System** es el sistema de diseño de Intibank, un banco digital ficticio con identidad visual inspirada en la cultura incaica (Inti, el dios sol). Proyecto de portafolio: versión reducida de un design system real, con tokens, guidelines y una librería de componentes.

## Cómo está organizado

- **Foundations** — tokens de diseño: color, y lo que se sume más adelante (tipografía, espaciado).
- **Componentes** — cada categoría (Forms, Feedback, Layout, Data display) agrupa los componentes de `intibank-ui` a medida que se documentan aquí.

La librería de componentes vive en el paquete `intibank-ui` y se documenta también en Storybook, que sirve como catálogo interactivo complementario a estas páginas.
